It reads the data file with fetch(), which browsers block on the file:// protocol and inside sandboxed previews. Either (a) serve the folder locally — cd au-dc-observatory/viewer && python3 -m http.server 8000 — then open http://localhost:8000, or (b) work directly from exports/australian_data_centre_observatory.db (SQLite) or exports/csv/*.csv. The embedded fallback below is a static snapshot of the headline tables.
Every row in this database carries a source id, a fact status (VERIFIED / REPORTED / CLAIMED / GAP) and a confidence grade. CLAIMED and GAP rows are unverified and must not be published as fact. See reports/build_report.md.
